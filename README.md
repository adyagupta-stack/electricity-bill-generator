# Electricity Bill Generator

A simple Python project that calculates electricity bills based on consumer details and meter readings.

## Features
- Accepts consumer name and ID
- Calculates electricity units consumed
- Computes energy charges
- Adds 5% electricity duty
- Includes a fixed meter charge of ₹100
- Displays a formatted electricity bill

## Technologies Used
- Python

## How to Run

1. Install Python.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python billgenerator.py
```

5. Enter the consumer details and meter readings when prompted.
